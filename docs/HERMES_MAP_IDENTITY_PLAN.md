# Hermes Map Identity Plan

## Cel

Zachować zatwierdzoną kompozycję, skalę, drogi, anchory, kadr i czytelność. Zmienić język wizualny tak, aby świat był rozpoznawalny jako Hermes, a nie jako mapa z Heroes III.

Kierunek: **żywe sanktuarium operacyjne AI / Hermes Nexus**.

- 60% fantasy: kamień, rękodzieło, rytuał, ogród, woda, mosiądz;
- 40% AI infrastructure: rdzeń, pryzmaty, runiczne szkło, magistrale danych, mechanizmy pracy;
- zero cyberpunku;
- zero klasycznej skórki „zamek + niebieskie kryształy”.

## Composition Lock

Nie zmieniamy:

- footprintów budynków;
- dróg, wejść i waypointów;
- centralnego placu;
- kadru mobilnego;
- hierarchii mapy;
- pozycji agentów;
- skalowania zatwierdzonej planszy.

Najpierw archiwizujemy master mobile/desktop i zapisujemy screenshoty referencyjne.

## Dlaczego mapa kojarzy się z klasyczną strategią fantasy

Skojarzenie tworzy suma, nie sama izometria:

- czerwone stożkowe dachy;
- jasny piaskowiec;
- regularne baszty i blanki;
- chorągwie;
- symetryczny bruk;
- pełny obrys muru;
- złote ornamenty bez znaczenia operacyjnego.

## 10 zmian najwyższej dźwigni

1. Wprowadzić trzy sygnatury marki: Hermes Core, świetlne żyły danych i lokalne aury stanu. Każdy kadr ma zawierać co najmniej dwie.
2. Zmienić materiały: grafit, ciemny łupek, oksydowany metal, kość/ceramika, postarzany mosiądz. Ciepło wyłącznie w miejscach pracy.
3. Osłabić terakotę i złoto; cyan/aether oznacza dane, amber/coral wyłącznie warning/error.
4. Stożkowe dachy przemalować na segmentowe osłony z ciemnego łupka i jednym świetlnym nerwem; footprint bez zmian.
5. Blanki, flagi i baszty reinterpretować jako pierścień obserwatorium, pylony i otwarte portale transmisyjne.
6. Bruk powierzchniowo zmienić w szlaki sygnału biegnące tymi samymi trasami. Puls tylko przy prawdziwym przepływie.
7. Fontannę zmienić w Hermes Core: lewitujące warstwy/pierścienie, czytelny puls systemu nawet jako miniatura.
8. Każdy budynek rozpoznawać funkcją: Archive = pamięć warstwowa, API = relay, Cron = oscylator, Forge = kompilator.
9. Obrzeża zmienić w kieszeń rzeczywistości: uskoki, mgła głębi, subtelna zorza i bioluminescencyjna flora.
10. Skleić postacie z mapą tym samym językiem holograficznych akcentów, ale agent pozostaje ważniejszy niż efekt budynku.

## Trzy magistrale

Nie łączymy wszystkiego ze wszystkim.

1. Command Spine: Hermes Core → Scheduler → budynki agentów.
2. Knowledge Loop: API Docks → Knowledge Archive → Model Crucible → Verification.
3. Operations Loop: Observability → Runtime Workshop → Incident Hall → Hermes Core.

W spoczynku prawie niewidoczne. Aktywny jest tylko krótki segment odpowiadający realnemu przepływowi.

## Pierwszy art pass bez przebudowy mapy

1. Zablokować kamerę, footprinty, drogi i anchory.
2. Global grade: zbić czerwień dachów około 80%, żółć kamienia około 45%, przyciemnić zieleń.
3. Przemalować pięć motywów: dachy, chorągwie, krenelaż, bruk, fontannę.
4. Dodać 4–6 conduits oraz 5–6 beaconów o jednym języku formy.
5. Zbudować trzy landmarki: Hermes Core, System Pulse Well, API Docks.
6. Dodać jeden hero moment prawdy: active agent zapala trasę, budynek odpowiada, reszta świata pozostaje spokojna.
7. Wyrenderować dokładnie 390×844 i 1440×900.
8. Wykonać blind test bez logo i tekstowych overlayów.

## Antywzorce

- czerwone spiczaste dachy + złote flagi;
- pergaminowe/bevelowane UI;
- pełny mur z regularnymi basztami;
- siatka, heksy, minimapa, fog of war i resource bar;
- bohaterowie z ekwipunkiem/statami RPG;
- identyczny neon na każdym budynku;
- ciągłe pulsy udające aktywność backendu;
- cyberpunkowy HUD doklejony do średniowiecznej ilustracji;
- dwanaście efektów naraz na telefonie;
- wielkie stałe etykiety;
- przypadkowy mash-up steampunk/anime/medieval;
- przebudowa layoutu przed potwierdzeniem języka w jednym paintoverze.

## Mobile readability

- agent ma lokalnie większy kontrast niż tło;
- pod trasami agentów tekstura jest spokojniejsza;
- żaden efekt nie działa bezpośrednio pod stopami poza cieniem;
- na pełnej mapie widoczne są: sylwetka, jedno urządzenie budynku, jedno światło stanu, problem, paczka;
- drobne ornamenty i część hologramów pojawiają się dopiero na zoomie/desktopie;
- semantyka kolorów statusu jest identyczna w całym świecie.

## Kryteria akceptacji

1. Po 3 sekundach odbiorca mówi „żywy system”, „AI sanctuary” albo „miasto agentów”, nie „zamek strategiczny”.
2. Bez promptowania maksymalnie 1/5 testerów wymienia Heroes jako pierwsze skojarzenie.
3. Na 390 px rozpoznawalne są aktywny agent, problem i źródło pracy.
4. W grayscale znika rytm czerwonych daszków i regularnych baszt.
5. Żaden efekt aktywności nie działa bez mapowania do backendu/logu.
6. Żaden budynek nie polega wyłącznie na niebieskim krysztale jako znaku AI.
7. Mapa pozostaje spokojna w idle i nie świeci cała naraz.
8. Wszystkie wejścia i trasy nadal zgadzają się z działającą choreografią agentów.
